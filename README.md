# LIÊN HOA — TIẾNG TRUNG GIAO TIẾP 365

Web app học tiếng Trung giao tiếp của Liên Hoa Global Education.

## Chức năng
- Trang chủ và bài học hôm nay
- Lộ trình HSK 1–6
- Luyện nói bằng Web Speech API
- AI Giáo viên hội thoại demo
- Flashcard từ vựng
- Theo dõi tiến độ
- Trang quản trị demo
- PWA/offline cơ bản
