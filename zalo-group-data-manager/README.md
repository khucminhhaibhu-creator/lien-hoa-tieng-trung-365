# Zalo Group Data Manager

App độc lập quản lý dữ liệu nhóm Zalo, giao diện mobile/desktop.

## Bản miễn phí hiện tại
- Quản lý nhóm, thành viên, tin nhắn.
- Tìm kiếm.
- Nhập/xuất CSV.
- Lưu dữ liệu trên trình duyệt.
- Cấu hình OA ID, App ID và backend URL.
- Có dữ liệu mẫu để kiểm thử.

## Zalo API thật
Zalo Developers hiện cung cấp hệ sinh thái Zalo Official Account, nhóm chat GMF, webhook và công cụ API. API thật cần OA/App được Zalo cấp quyền. Không đưa Access Token vào GitHub Pages; token nên nằm ở backend bảo mật.

## Chạy
Mở `index.html` bằng GitHub Pages. Có thể dùng thư mục này độc lập bên trong repository hiện tại.
